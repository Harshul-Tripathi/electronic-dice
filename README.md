# Electronic Dice

A custom fully analog Electronic Dice PCB designed in KiCad using discrete logic, THT components, and a single 3V CR2032 battery. Shake the board or press the button to roll the dice, with LEDs flashing through the dice faces before settling on a random number.

## Features

- Shake-to-roll using an SW-520D vibration switch
- Push-button trigger
- CMOS 555 Timer clock
- CD4017 decade counter
- Diode and transistor logic for LED control
- Fully THT and hand-solderable
- Single 3V CR2032 power source
- No microcontroller or code required
